# 公差幸存者

岑岭试制车间的计量设备出了故障。拾取实训室的手工具，核验三批样件，在 03:30 接手事故处置。测量单列出要求、实测读数和超差量。免检和美化记录能带来眼前收益，留下的隐患会改变后续冲击波，并列在交班报告里。

## 游玩

解压离线试玩包，双击其中的 `index.html`。游戏使用 WebGL 2。首次开始进入可跳过的新手训练，也能从标题页单独重练。

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD 或方向键 | 拖动场地或左下摇杆 |
| 冲刺 | 空格 | 快划场地或点击「冲刺」 |
| 拾取普通工具 | 走进绿色光圈 | 走进绿色光圈 |
| 切换已解锁工具 | 按 1 至 6 或点击工具栏 | 点工具栏的图标 |
| 使用捷径 | 靠近后按 E | 靠近后点击「放行」或「改写」 |
| 合规复检 | 在绿色复检圈内停留 1.6 秒 | 在绿色复检圈内停留 1.6 秒 |
| 升级 | 点击卡片或按 1 到 3 | 点击卡片 |
| 暂停 | Esc 或点击「暂停」 | 点击「暂停」 |

游标卡尺就在出生点旁。其他手工具会在本班陆续掉落。拾起的第一把工具会自动装备，此后每次只使用工具栏里选中的一把。每把工具单独保留等级，切换会沿用当前攻击冷却。每件工具拾取后从 Lv.1 开始，收集实测量块可继续升到 Lv.5。选卡会显示伤害、攻击间隔和量程的变化，Lv.3 还会获得该工具专属的校准效果。

新手训练通过计量站对讲逐步发出指令。跟着地面箭头拾取卡尺，练习冲刺、收集量块、选卡，然后拾取并选中扳手。最后在同一批超差样件上体验复检隔离或免检放行，观察随后出现的冲击波。

| 工具 | 攻击方式 |
| --- | --- |
| 游标卡尺 | 自动瞄准附近目标，校准后更快、更远 |
| 扳手 | 重击近身扇区，打断螺栓蓄力 |
| 锉刀 | 连续锉削同一目标，锉屑波及附近零件 |
| 手锯 | 横向拉锯，扫过前方一排零件 |
| 卷尺 | 拉出长尺，贯穿同一直线上的目标 |
| 橡皮锤 | 近身震击，推开周围零件 |

## 班次事件

0:32、2:02 和 3:00 有进料高峰。地面先标出入场位置，随后两批零件先后抵达。0:50、1:40 和 2:30 另有需要处置的待检批次。按 E 签免检可立即清场，改写记录则可短时加速。留在绿色复检圈内 1.6 秒，可保留原始读数、隔离同一批剩余待检件并恢复部分生命。

03:30 后，附近的部分零件会进入事故处置。沿绿色缺口避开冲击波，试验台还会间歇锁定一块矩形落区，标线出现后及时离开。使用捷径的批次会按隐患数在事故战中回流零件，交班报告会统计隐患造成的伤害。冲刺冷却最后约 0.13 秒内的按键或快划会在就绪时执行。

交班报告逐批列出原值、处置和后果。完成三批复检并击停试验台才能验收。击停后仍有漏检批次会暂缓交付，使用捷径的批次需要追回复核。

## 本地开发

需要 Node.js 24 和 npm。

```sh
npm ci
npm run dev
npm test
npm run build
```

校准台、抽样传送台和隔离料架需要绕行。超差件会分散追击和侧包，螺栓预告冲撞方向，撞上工位后会停下来。假数据会在侧面找射击角度，直线弹道可被工位挡住。

TypeScript 模拟按固定的 60 Hz 步长推进。工位布局同时用于车间模型、碰撞和敌群寻路。小怪受挡时共享到玩家附近的网格路径，并通过空间分桶与近邻保持间距。Three.js 渲染原创关节模型、车间和成批精灵，通过按视口调整的低分辨率渲染目标保留像素边缘。小怪和工具图集由 Canvas 绘制，音效和配乐由 Web Audio 合成。Vite 8 和 Rolldown 将浏览器入口打成可离线加载的普通脚本。

固定种子测试覆盖工具拾取与升阶、两种捷径、冲击波、结算和完整跑局回放。素材、界面和车间布局为本作原创，以 Tibo.dog 的移动与升级节奏作为同类游戏参考。

| 配置 | 值 |
| --- | --- |
| 生产分支 | `main` |
| 根目录 | 仓库根目录 |

| 安装命令 | `npm ci` |
| 构建命令 | `npm run build` |
