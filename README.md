# 公差幸存者

岑岭试制车间的计量设备出了故障。拾取实训室的手工具，撑过不断涌入的超差件，在 03:30 接手事故处置。免检和美化记录能带来眼前收益，留下的隐患会改变后续冲击波，并列在交班报告里。

## 游玩

解压离线试玩包，双击其中的 `index.html`。游戏使用 WebGL 2。首次开始进入可跳过的新手训练，也能从标题页单独重练。

| 操作 | 电脑 | 手机 |
| --- | --- | --- |
| 移动 | WASD 或方向键 | 拖动场地或左下摇杆 |
| 冲刺 | 空格 | 快划场地或点击「冲刺」 |
| 拾取普通工具 | 走进绿色光圈 | 走进绿色光圈 |
| 使用捷径 | 靠近后按 E | 靠近后点击「拾取」 |
| 合规复检 | 在绿色复检圈内停留 1.6 秒 | 在绿色复检圈内停留 1.6 秒 |
| 升级 | 点击卡片或按 1 到 3 | 点击卡片 |
| 暂停 | Esc 或点击「暂停」 | 点击「暂停」 |

游标卡尺就在出生点旁。其他手工具会在本班陆续掉落。每件工具拾取后从 Lv.1 开始，收集实测量块可继续升到 Lv.5。选卡会显示伤害、攻击间隔和量程的变化，Lv.3 还会获得该工具专属的校准效果。

| 工具 | 攻击方式 |
| --- | --- |
| 游标卡尺 | 自动瞄准附近目标，校准后更快、更远 |
| 扳手 | 重击近身扇区，打断螺栓蓄力 |
| 锉刀 | 对同一件零件进行三次连续锉削 |
| 手锯 | 横向拉锯，扫过前方一排零件 |
| 卷尺 | 拉出长尺，贯穿同一直线上的目标 |
| 橡皮锤 | 近身震击，推开周围零件 |

## 班次事件

0:50、1:40 和 2:30 会出现不同的待检批次。琥珀色和紫色地面标记提前提示涌入方向。按 E 选捷径可以马上清场或短时加速，隐患随后进入事故战。进入绿色复检圈后持续站稳 1.6 秒，可以隔离同一批剩余待检件并回收部分生命。已处理的批次会出现在交班报告里。

## 本地开发

需要 Node.js 24 和 npm。

```sh
npm ci
npm run dev
npm test
npm run build
```

TypeScript 模拟按固定的 60 Hz 步长推进，显示刷新和暂停由浏览器界面处理。Three.js 绘制车间和成批精灵，再通过低分辨率渲染目标保留像素边缘。像素图由 Canvas 程序绘制，音效和配乐由 Web Audio 合成。Vite 8 和 Rolldown 将浏览器入口打成可离线加载的普通脚本。

固定种子测试覆盖工具拾取与升阶、两种捷径、冲击波、结算和完整跑局回放。素材、界面和车间布局为本作原创，以 Tibo.dog 的移动与升级节奏作为同类游戏参考。

## EdgeOne Makers

从 GitHub 导入仓库后使用以下构建参数。

| 配置 | 值 |
| --- | --- |
| 生产分支 | `main` |
| 根目录 | 仓库根目录 |
| Node.js | `24` |
| 安装命令 | `npm ci` |
| 构建命令 | `npm run build` |
| 产物目录 | `dist` |
| 环境变量 | 留空 |
